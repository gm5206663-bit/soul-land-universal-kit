# _alt_drafts — drafts kept, never canon

Nothing in this folder is part of the serial. Chapters live in `../chapters/`.

## Why it exists
On 2026-09-23 (session 49) two delegated agents answered the author's word
"Next chapter" at the same time. The chapter that reached GitHub first
(`../chapters/Chapter_22_The_Deep_Forest_Proper.md`) is the live one and stands;
the second draft is kept here whole, labelled, so that no written work is thrown
away and the author can rule if he wants the other shape. Recorded in
`../foundation/SERIAL_LOG.md` (s49 addendum) and in the control centre.

| File | What | Status |
|---|---|---|

Law for this folder: a draft lands here only when it is displaced by something
already published, never to stage a rewrite of a shipped chapter.
