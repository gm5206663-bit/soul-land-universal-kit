# STORYOS ADAPTATION TALENT FIREWALL v3.0

## Core definition
Treat Adaptation Talent as a separate innate talent whose result depends on the individual's complete current foundation and the laws/resources of the setting.

Evaluate:
BODY / BIOLOGY / CELLS / ORGANS / PSYCHOLOGY / COGNITION / INSTINCTS / SENSES / SPIRIT OR SOUL / WILL / ENERGY SYSTEMS / INNATE TALENTS / EXISTING POWERS / POTENTIAL / EXPERIENCE / TRAINING / AVAILABLE RESOURCES / WORLD LAWS.

## Individualization rule
Do not assume Adaptation improves every category equally or at all. Determine the actual bottleneck and the form of adaptation the foundation can support.

## Conservation rule
Adaptation refines, integrates, and responds using available foundations/resources. It does not create arbitrary energy, bypass explicit world laws, or guarantee victory.

## Failure-as-data
Failure can provide information for future adaptation, but adaptation still needs time, exposure, effort, and compatible mechanisms unless the setting explicitly says otherwise.

## Divine escalation
If an established story system permits higher-order adaptation, treat adaptation to fate/time/luck/etc. as a separate advanced development requiring explicit foundation rather than an automatic baseline effect.
