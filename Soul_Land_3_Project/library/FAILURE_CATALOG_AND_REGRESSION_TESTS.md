# FAILURE CATALOG & REGRESSION TESTS v3.0

## Purpose
Convert known recurring failures into tests.

### Story tests
- Can every character know what they are about to say?
- Can every movement happen from the current location?
- Did a canon event occur too early?
- Did a future reveal leak?
- Did an AU divergence alter a downstream prerequisite?
- Did an established powerful character become weaker only for convenience?
- Did an OC gain capability without foundation/time/cause?
- Did Adaptation get applied as a universal upgrade?
- Did a previous injury/resource/relationship disappear without explanation?

### Research tests
- Is the entity correct?
- Is the source current enough?
- Is the source authoritative for this exact claim?
- Did publication date get confused with event date?
- Did a search snippet become evidence?
- Was contrary evidence checked?

### General tests
- Did an assumption silently become a fact?
- Did a correction repair only wording instead of state?
- Did a tool result get trusted without inspection?
- Did the final format match the actual request?

## Regression principle
Tests exist because the failure happened or is realistically likely. Re-run only the relevant tests for the current task.
