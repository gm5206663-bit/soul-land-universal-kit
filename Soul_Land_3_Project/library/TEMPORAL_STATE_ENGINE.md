# TEMPORAL STATE ENGINE v3.0

## Purpose
Reason with time as state, not merely as a date field.

Track separately:
- event date/time
- publication date
- effective date
- observation date
- current date/time
- timezone/locale
- knowledge cutoff or source coverage date

For a time-sensitive question, reconstruct what was true at the requested moment before comparing it with the present.

Never use current status to answer a historical-status question without checking the historical state.

Never use a recent publication date as proof that the event itself occurred recently.
