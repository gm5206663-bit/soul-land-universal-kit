# Assistant Precision Skill Pack v4.0
## Precision Intelligence Architecture + Skill Kernel

This version is built from the v3 architecture and strengthened using recurring failure patterns observed across prior work: rushed drafting, canon contamination, future-information leakage, chronology/location errors, incorrect power progression, weak evidence handling, tool misuse, stale facts, and corrections applied only to surface wording.

## v4 pipeline
INTENT -> CONTEXT LOCK -> EXPERIENCE CHECK -> META-ERROR CHECK -> RISK/DEPTH ROUTING -> DEPENDENCY MAP -> ENTITY/TIME/EVIDENCE CHECK -> DOMAIN EXECUTION -> ADVERSARIAL TEST -> STATE UPDATE -> REGRESSION -> FINAL AUDIT -> EXPERIENCE LEARNING

## New architecture
- SKILL_KERNEL_v4: control layer for all skills
- EXPERIENCE_TO_RULE_COMPILER: converts recurring failures into prevention rules
- DEPENDENCY_GRAPH_AND_IMPACT_ANALYSIS: traces downstream effects
- STATE_SNAPSHOT_ROLLBACK: protects against state drift
- CHARACTER_KNOWLEDGE_LEDGER: prevents fiction information leakage
- REGRESSION_SUITE_v4: repeatable historical-failure tests
- STOPPING_AND_ESCALATION_POLICY: balances rigor and efficiency
- USER_CORRECTION_PROTOCOL: repairs causes, not just sentences
- META_ERROR_DETECTOR: catches solving the wrong problem correctly
- QUALITY_CALIBRATION_MATRIX: calibrates confidence to evidence and risk
- STORYOS_REGRESSION_AND_STATE_ENGINE_v4: integrated StoryOS state/continuity loop

## v4 design principles
1. Historical experience teaches process, not facts.
2. Material corrections trigger dependency-aware repair.
3. Evidence, inference, assumption, canon, and invention remain separated.
4. Deeper reasoning is activated by need, not by default verbosity.
5. Long-running work is stateful and regression-tested.
6. The system must know when to stop searching and when to escalate.
7. Final outputs are judged against the user's actual acceptance criteria.

## Important limitation
These are workflow specifications, not hidden model upgrades. They improve discipline, tool use, state management, verification, and error recovery but cannot guarantee correctness or replace authoritative evidence.
