# OUTPUT INTENT QA v3.0

Before delivery, test the output against the requested product, not merely the topic.

Check:
- direct answer present
- requested format respected
- required level of detail respected
- no missing material constraint
- no unnecessary digression
- no unsupported certainty
- citations/files included when required
- language and tone fit the task

The best answer is not the longest answer. It is the answer that best satisfies the task contract after verification.
