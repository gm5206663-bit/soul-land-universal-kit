# STORYOS CANON DIVERGENCE ENGINE v3.0

## Purpose
Track exactly where an AU separates from canon and propagate the consequences.

For each divergence record:
- canon expectation
- actual AU event
- reason
- immediate changed variables
- downstream dependencies
- canon events still valid
- canon events now conditional
- canon events invalidated
- new uncertainty introduced

## Event dependency rule
A downstream canon event may be preserved only if its necessary prerequisites still hold.

## No retroactive contamination
Later AU knowledge must not be inserted into earlier scenes unless an in-universe mechanism makes that knowledge available.
