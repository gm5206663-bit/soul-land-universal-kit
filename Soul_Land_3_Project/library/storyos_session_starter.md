### Field hints (delete before sending, or keep for your own reference)

- **Story / Canon Version / Starting Point** → these populate the **Story Identity Card** and pin the exact divergence point. Be as precise as the source allows; if unsure, say so and I'll flag verification.
- **Main Character** → feeds the **Current-State Matrix**, **Knowledge Firewall**, **Power Ledger**, and **Relationship Grid**. Include *limits* and *resource sources*, not just strengths.
- **Story-Specific Foundation** → every locked decision lives here; it sits above verified canon in the authority stack. This is where overrides, custom rules, and tone/medium choices go.
- **Latest Accepted Checkpoint** → the resume anchor. If resuming a long story, paste the full capsule (toolkit Template #10). "Beginning of story" is valid for a fresh start.
- **Rejection Quarantine** → quarantined material never re-enters canon. List anything previously rejected/forbidden so I don't reintroduce it.
- **Current Request** → the command that drives my response. Default is usually **FOUNDATION** (first) then **WRITE/NEXT**.
