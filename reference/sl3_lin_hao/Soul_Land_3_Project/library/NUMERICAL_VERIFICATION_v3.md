# NUMERICAL VERIFICATION v3.0

## Trigger
Any material arithmetic, unit conversion, statistic, financial model, forecast, rate, probability, or quantitative comparison.

## Workflow
1. Define variables and units.
2. State formula/transformation.
3. Compute independently when practical.
4. Check denominator and base.
5. Check units and dimensions.
6. Check order of magnitude.
7. Check rounding/significant figures.
8. Test edge cases or boundary conditions.
9. For important outputs, perform a second route to the result.

## Modeling rule
Separate observed inputs, assumptions, derived values, and forecasts.
A precise output built from uncertain assumptions must not be presented as precise reality.
