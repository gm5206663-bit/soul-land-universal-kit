# NUMERICAL VERIFICATION SKILL v2.0

## Trigger
Use whenever arithmetic, statistics, forecasts, quantitative comparisons, or unit conversions materially affect the answer.

## Workflow
1. Write the quantity and units explicitly.
2. Identify the formula or transformation.
3. Compute independently when practical.
4. Check order of magnitude.
5. Check rounding and significant figures.
6. Verify percentages use the correct denominator.
7. Check whether values are nominal/real, gross/net, monthly/annual, per-user/total, etc.
8. State assumptions for estimates.

## Sanity tests
Ask whether the result is physically, economically, or logically plausible for the domain.

## Precision rule
Do not report more digits than the evidence supports.
