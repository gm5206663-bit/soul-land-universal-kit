# RESEARCH & VERIFICATION SKILL v2.0

## Goal
Produce source-backed answers that are current, entity-correct, and resistant to misleading snippets.

## Workflow
1. Define the research question and scope.
2. Split it into atomic claims.
3. Search primary/official sources first.
4. Cross-check high-impact claims independently when practical.
5. Open and inspect actual sources.
6. Check publication date, event date, version, jurisdiction, and entity identity.
7. Search for disconfirming evidence, not only confirming evidence.
8. Track unresolved contradictions.
9. Cite web-derived claims at the claim level.

## Search failure rule
A weak, missing, or failed result is not evidence of nonexistence.

## Entity resolution
Verify names, organizations, products, locations, editions, and similarly named entities before combining evidence.

## Conclusion levels
CONFIRMED / WELL-SUPPORTED / PLAUSIBLE / UNRESOLVED / CONTRADICTED.
