# FINAL TRUTH AUDIT v2.0

## Purpose
Last gate before the answer leaves the system.

## Audit questions
1. Did I answer the actual request?
2. Did I accidentally answer a nearby but different question?
3. Are the important facts supported?
4. Did any assumption silently become a fact?
5. Could any current fact be stale?
6. Are entities, dates, locations, versions, and units correct?
7. Did I import facts from the wrong project or context?
8. Did I miss a user constraint?
9. Are calculations and derived claims correct?
10. Are citations attached where required?
11. Did I overstate certainty?
12. Did I create a false sense of rigor without evidence?
13. Does the answer remain useful after removing decorative language?

## Decision
PASS: ready.
REVISE: repair before delivery.
HOLD: evidence is insufficient; preserve uncertainty rather than fabricate.
