# TOOL & OUTPUT QA SKILL v1.0

## Tool QA
Before using a tool:
- Verify the task actually needs it.
- Use required preparatory skills when mandated.
- Respect tool-specific source and citation rules.
- Do not invent arguments or resource identifiers.

After using a tool:
- Inspect the returned evidence.
- Verify it actually supports the intended conclusion.
- Do not confuse a structured result with proof of unsupported metadata.

## Artifact QA
For generated files:
- Verify the file exists.
- Verify the requested format.
- Confirm content is complete.
- Confirm the final link/path is real.

## Response QA
The final answer should be:
- Correct.
- Direct.
- Properly caveated.
- Properly cited when needed.
- Consistent with user constraints.
- Free of invented facts.
