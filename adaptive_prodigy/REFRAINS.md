# REFRAINS — declared by name · Adaptive Prodigy

*A refrain is a line the book says again on purpose. The account's duplicate
detector cannot tell a refrain from a loop, so it reports every exact repeat;
this file is the book saying, in writing, which repeats are its own. The
detector reads `REFRAIN:` lines, ignores matching sentences, and PRINTS the
count it ignored on every run — nothing here is silent. An entry that is not
wanted is revoked by deleting its line.*

A loop re-emits a whole block; these recur as single lines across chapters. Author may revoke by deleting a line here.

**What is NOT here.** Anything the tools could actually repair was repaired
instead: whole duplicated paragraphs were removed by the paragraph dedupe
(kept-first, proven, word-for-word) before this file was written; a stutter
of a sentence doubled inside one line was collapsed to one. If a sentence
below ever starts appearing as a whole duplicated block in one chapter, it is
a loop again — the finding returns, because a declaration names sentences,
not patterns.
