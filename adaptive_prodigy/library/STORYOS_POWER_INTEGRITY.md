# STORYOS POWER INTEGRITY v3.0

## Purpose
Prevent arbitrary power inflation, artificial nerfing, and category confusion.

Maintain separate axes:
RAW CAPACITY / OUTPUT / CONTROL / PRECISION / TECHNIQUE / KNOWLEDGE / EXPERIENCE / COMPATIBILITY / STAMINA / RESOURCE ACCESS / SPEED OF EXECUTION / POTENTIAL.

## Conflict analysis
Ask whether the difference comes from capability, mastery, information, environment, matchup, resources, or strategy.

## Established-character respect
Do not make canonically capable characters incompetent solely to spotlight an OC.

## OC progression
New capabilities require a plausible foundation and integration path. A talent that improves adaptability or learning does not automatically erase the need for practice, resources, or world-law constraints.
