# TOOL SELECTION & TOOL RESULT AUDIT v3.0

## Before using a tool
Ask whether the tool will materially improve accuracy, access, calculation, execution, or verification.
Confirm the correct tool, exact schema, required prerequisites, and available identifiers.

## After using a tool
Check:
- did it answer the intended subproblem?
- was the entity correct?
- is the result current enough?
- was it truncated?
- does the result actually support the inference?
- did the tool fail silently or return partial data?

Never treat tool output as inherently authoritative.

## Artifact rule
Verify actual file existence, format, content, calculations, references, and user-visible link/path before claiming success.
