# EVIDENCE GRAPH & PROVENANCE v3.0

## Purpose
Track not merely sources, but how evidence supports conclusions.

Represent:
SOURCE -> OBSERVATION -> CLAIM -> INTERMEDIATE CONCLUSION -> FINAL CONCLUSION

For each material edge, evaluate authority, directness, freshness, independence, and conflict.

Independence rule: ten copies of the same source are not ten independent confirmations.

User-provided project canon can be authoritative for that project state when the user explicitly establishes it. Public canon and external sources should not silently overwrite the project's locked state.

Citation rule: support the exact adjacent claim. Do not cite a source merely because it is about the same topic.
