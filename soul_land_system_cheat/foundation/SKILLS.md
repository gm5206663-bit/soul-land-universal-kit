# SKILLS — the ledger of the soul's skills

v1.0, 2026-09-25. THE SKILLS LAW (SC22): **the spirit's own ability is the
FIRST skill — seated, named, and counted like everything else.** Every ring
seats exactly one more (the cultivar lock). Each skill carries its own
incantation, spoken in the mind, never aloud; each moves at its own pace
(SC21); aging deepens a ring's skill without ever changing what it is.
Skills are not slotted — the spirit is his, and a ring's skill rides its
ring's seat. Names are the System's descriptive naming — PROPOSED,
strikeable.
