## THE FIVE FAILURES (why this foundation exists)

1. **No canon spine** — canon must HAPPEN on the page. ≥5 named canon beats, lock 3.
2. **Nothing contested** — every chapter gets a threat and a face.
3. **No felt progression** — ranks, rings, forge-stars, armor words MOVE on the page.
4. **One register repeated** — ≥3 of 5 registers per chapter; dialogue is mandatory.
5. **Apparatus outgrowing story** — bookkeeping lives in the kit files, prose stays prose.
