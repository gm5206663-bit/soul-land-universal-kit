# CANON_ACCESS.md — how canon ore enters The Grey Wolf

## The spine vs the anchors

- **Spine (load-bearing):** **Soul Land II: The Unrivaled Tang Sect era** —
  declared in `CANON_GROUND.md` § The spine, v1.0 (2026-09-25). The serial's
  clock, ranks, ring limits and awakenings ride this spine.
- **Anchors (citable, never load-bearing for beats):** the Soul Land fandom
  wiki, Baidu Baike (EN mirror), and the WebNovel official translation — the
  three sources `CANON_GROUND.md` was gathered from. Donghua/manhua panels
  may illustrate, never settle a fact alone.
- **Ore rule:** anchors may support a claim with a receipt; only the spine
  decides what beats happen. A conflict between anchors is recorded with both
  readings — never silently switched (kit `01_CANON_SPINE.md` discipline:
  [canon] / [fan] / [disputed] / [design]).

## What never enters

- Rejected drafts; fan wikis as load-bearing sources; author/agent knowledge
  as character knowledge (`RELATIONSHIPS.md` firewalls); any claim absent
  from `CANON_GROUND.md` — access without a receipt is not access.

**Honest gap (recorded, not hidden):** a per-episode `canon_extract/` tree was
never built for this serial. The receipts carried so far have been enough;
if a beat needs scene-level reconstruction, extract first, then draft — say
so in `SERIAL_LOG.md` when it happens.
