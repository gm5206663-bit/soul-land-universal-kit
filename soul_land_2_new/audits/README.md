# audits/ — per-chapter validation receipts

Pattern: `soul_land_4_fire_phoenix/audits/`.

Every chapter ships with two receipts:
1. `canon_coverage/Canon_Coverage_Chapter_NN.md` — canon threads touched, tier (VERIFIED vs canon-true vs [design]), leak check.
2. `audits/CHAPTER_NN_VALIDATION_<date>.md` — register compliance vs the Fire Phoenix anchor + 7-point contract + story-laws sweep + residual risks.

Authorization gate: no chapter body without the author's word. His read is the final gate over any mechanical audit.
