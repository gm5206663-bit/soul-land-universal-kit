# Terminology and translation consistency

| Preferred working term | Scope / aliases to reconcile |
|---|---|
| Yan Jingheng / 言景衡 | Delegated OC name; surname is 言, following the chosen paternal identity |
| Huo Yuhao | Canon protagonist; do not alternate with an unrelated transliteration |
| Cai Mei’er | Typographic apostrophe variants identify the same person |
| Bright Phoenix | Approved paternal foundation; translation aliases do not grant additional souls |
| Evil-Dispelling Dragon Soul Spear | Author-adopted maternal donghua foundation, not a verified named novel soul |
| Adaptation Talent | Separate complete-existence Talent, not a system or third martial soul |
| martial soul | Some English sources use spirit; preserve identity across editions |
| soul power / cultivation rank | Native-world energy/rank terminology, not engineering certification |
| soul ring | Donor, age, present state and skill remain separate records |
| Soul Elder / Soul Venerable | Translation variants requiring edition consistency, not automatically different realms |
| soul engineer | Technical craft; proficiency, personal output, device level and certification differ |
| Star Dou Forest | Keep chosen English spelling; translation variants do not create another forest |
| O | Author-facing chronology anchor: first stream meeting, never a term spoken by the characters |
| primary-read | Specific narrative body actually reviewed |
| official-metadata | A genuine listing, not panel/episode consumption |
| delegated-design | Agent-owned development under author delegation; not a fabricated author quote |

No universal low/mid/high/ultimate technique ladder, terminal interface, spiritual
power statistic or later-era system is imported from another serial’s glossary.
When adding a translation, record its source edition and use one prose form.
