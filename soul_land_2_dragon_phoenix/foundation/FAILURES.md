# Failure prevention ledger

This project has no rejected prose chapter. The following are known process or
design risks, not invented stories about failures Jingheng has already suffered.

| Risk | Prevention / accountable owner |
|---|---|
| File count mistaken for completed power derivation | OPEN_WORK.md and ready gate remain honest |
| Thin relationship list mistaken for a lived bond | Dossiers supply distinct working texture; prose must demonstrate it |
| Childhood power erased to preserve canon staging | DEVELOPMENT.md, RESOURCES.md and causal opening review |
| Exact rank/ring ages guessed for an attractive panel | Causal development events and source receipts before current-state acceptance |
| Manhua catalog or episode listing treated as a scene | SOURCE_RECEIPTS.json separates access scopes |
| Genealogy silently rewritten from a wiki | FAMILY_TREE.md preserves author branch and unresolved links |
| Other serial’s grades, UI, illness or numbers transferred | GitHub review is structural only; source walls remain |
| Ma future settled through a casual label | Explicitly open bond in current state and relationship dossier |
| Ancestors become secret teachers | No contact or learned memory in accepted premise |
| Canon character’s private history becomes OC knowledge | KNOWLEDGE_FIREWALL.md and per-scene witnesses |
| Deleted research pictures recreated as an asset pack | Latest author deletion receipt; text-only project scope |

If a real defect is found, record date, affected files/scenes, cause, correction,
regression check and any remaining uncertainty. Do not call a mechanical PASS
proof that every creative or external-source problem has been solved.
