# Chapter production workflow

## 1. Research and state

Read applicable author rulings, live state and open work. Review actual source
bodies/visual units for the proposed coverage. Record edition and exact units;
never use a catalog title as evidence of a scene. Resolve the opening numerical,
ring, engineering and source blockers before Chapter 1 prose.

## 2. Plan the scene, not a checklist recital

Choose start/end events, POV, place, participants and a change that matters.
Keep the canon characters’ independent goals. Identify where Jingheng’s actual
presence changes a cause, decision or consequence. Do not invent an absence so
a familiar injury can happen unchanged.

## 3. Draft original prose

Use the source’s dramatic logic without copying its wording. Introduce past
history through present relevance. Keep child depiction age-appropriate and
avoid stat dumps. Natural dialogue should reveal the existing bonds before
explaining their full history.

## 4. Audit the result

Check source coverage, timeline, knowledge boundaries, character agency, equipment,
resource use and all abilities used. Measure the local style targets, review
repetition and dialogue, and inspect the scene for naturalness. A mechanical
PASS cannot establish creative quality or external canon truth.

## 5. Commit continuity and publish

Update accepted live state and actual continuity events, not proposal files.
Generate status/file map, run all checks, inspect the precise diff, preserve
other agents’ files and use non-force publication. Public links and receipts
must match the actual shipped chapter. No chapter is registered before prose exists.

The present release is still foundation-only. The current ready command must
refuse drafting while its genuine blockers remain; do not alter that result
merely because the rest of the file architecture is now present.
