# Local power system — sources and measurements stay separate

## Verified opening spine

Wuxiaworld 1.1–1.2 describes six-year martial-soul awakening, innate soulforce,
rank-ten full innate soulforce as a genius benchmark, cultivation and ring
bottlenecks. It explicitly places Yuhao at eleven, reaching rank ten after five
years. These are source facts about Yuhao/the world, not Jingheng’s opening numbers.

Use consistent English terms with a terminology ledger. Different translations
use Soul Elder/Soul Venerable and Spirit/Soul; a label variation is not a new stage.
Do not copy a source’s accidental count mismatch into an invented stage system.

## Separate axes

Cultivation rank · actual reserves · output/control · physique · soul/spiritual
capacity · bloodline expression · martial-soul development · ring gifts ·
learned technique · equipment · combat experience · engineer proficiency ·
certification · environmental advantage. No one axis automatically proves the others.

No SL3 spiritual-power numeric realm table, battle-armor system, spirit-soul
infrastructure or later-era standard is imported into early Soul Land II without
an actual setting/source and development route. No decorative SP number is assigned.

## Advancement and absorption

A gate has a mechanism. Adaptation can improve compatibility and supporting
capacity, but does not replace the missing ring with a slogan. Ordinary absorption
benchmarks are comparison data, not universal ceilings on an extraordinary
holder. Any exceptional ring requires an actual supported event.

Soul-ring color, donor age, current ring state and actual skill are separate
entries. “Years” is not a linear combat-score multiplier. Do not age rings by
the calendar or invent a universal passive aging ability from another holder.

## Current-state discipline

CURRENT_STATE.json uses null for undetermined values, never zero masquerading
as a weak starting state. OPENING_STATE_REVIEW.md is design evaluation, not the
accepted checkpoint. No total number of combat rings is invented merely because
there are two souls. Native ranks must not be added across souls.
