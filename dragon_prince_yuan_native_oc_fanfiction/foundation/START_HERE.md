## Absolute startup rule

Do **not** write Chapter 1 yet. First lock:

1. Source priority: novel vs manhua vs donghua.
2. Exact starting point.
3. OC identity/background.
4. OC cultivation/power path.
5. Relationship to canon cast.
6. Knowledge limits.
7. Tone/rating/chapter length.
8. Hard forbidden outcomes.

## Source conflict rule

If donghua, manhua, and novel differ:

- Do not silently merge them.
- Record each difference in `foundation/CANON_SOURCE_MAP.md`.
- Ask the user which version to follow.

## Butterfly rule

Because this is canon-aware with a native-born OC, public OC actions must produce natural consequences. The OC must not become invisible when they should affect clan politics, sect attention, cultivation resources, rivalries, tests, battles, or relationships.
