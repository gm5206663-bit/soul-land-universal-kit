# Chapter Workflow

For every chapter:

1. Read `foundation/STATUS_PANEL.md`.
2. Read `foundation/NO_MISTAKE_RULES.md`.
3. Read current character/power/relationship ledgers.
4. Verify canon source span.
5. Write/update canon coverage.
6. Draft prose.
7. Run audit:
   - continuity values,
   - power scaling,
   - knowledge firewall,
   - public/private identity,
   - source-order conflicts,
   - CJK/unwanted text if writing in English,
   - stale references.
8. Update status panel and ledgers.
9. Present the chapter.

No chapter is complete until support files are updated.
