# Canon Workflow

## Canon-first rule

Before writing any chapter:

1. Identify exact canon source span.
2. Fetch/read/check the source.
3. Record canon beats in `canon_coverage/`.
4. Separate public facts, private facts, narrator-only facts, and future-spoiler facts.
5. Decide how the fanfic premise changes public/shared events.
6. Only then write prose.

## Source conflict rule

If the user gives a source claim and fetched material conflicts with it:

- Do not blindly accept either side.
- Present the conflict clearly.
- Ask which source/numbering/version to follow.
- Record the decision in `foundation/CANON_SOURCE_MAP.md`.

## Coverage file must include

- Source URLs or user-provided source references.
- Canon summary.
- Who knows what.
- What changes naturally because of the OC/protagonist.
- Must-not errors.
- Current status at chapter start and end.
