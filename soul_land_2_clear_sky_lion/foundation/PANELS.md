# PANELS.md — panel grammar of Clear Sky Lion

## Declaration

**HAS_PANELS: yes** — declared by R15 (panels print on update/gain beats,
F22) with the house rule that exact figures live in panels/STATUS, never in
prose. **A no-System serial** (R7): panels are typeset stage-directions, not
a HUD — there is no menu, no percentage, no interface anywhere on page.

## Grammar

- Shape: bracketed status lines, cold and quiet, e.g. a ring/skill update
  printed once at the gain beat (exact format fixed when the chapter gate is
  built, with a receipt here).
- When full details print: **only on update or gain beats** (F22).
- When nothing prints: **every other beat — 0 lines** (F22).
- Where the truth lives between prints: `STATUS.md`, `SKILLS_CANON.md`.
- Figures: prose says "seven", the panel says "7" — prose carries none
  (R15).

## Rules

- Frozen meters fail the build: panel vs STATUS mismatch = gate red. Fix the
  panel or fix STATUS — never the checker.
- **No System styling** (R7): nothing that reads as an interface, an
  interface voice, or a percentage meter ever appears — even as metaphor.
