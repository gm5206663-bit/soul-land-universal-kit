## GROUND RULES (foundation stage)

1. **One premise.** We lock premise + protagonist before writing anything.
2. **Locks before prose.** No chapter until LAWS + state files exist.
3. **Source of truth lives here.** Old-project numbers never ride along into the new canon.
4. **Canon is the spine, not the script.** When the world is Douluo, donghua/manhua/novel order matters
   (donghua first, as the user required in past projects). Wiki is not a prose source.
5. **Quality bar** = real prose with body, cause→consequence, no skill-name stickers, no kit-recap-as-story,
   no robot chapters. Reference samples are in the map.
6. **Nothing absolute.** Power guesses (King/Emperor/Sage etc.) are guesses, not fixtures.
