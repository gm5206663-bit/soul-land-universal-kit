## 1. Exactness rule

Do not rely on broad category labels alone when a precise value matters.

Wrong pattern:

- a broad hundred-year-category label with no exact age.
- "solid mid-rank" with no level.
- "low-rank utility" with no level.
- "same family status for six years" with no adult growth.
- "open until needed" for a value that already affects current mechanics or resource logic.

Correct pattern:

- State the exact level or year value.
- State the stage/title/ring color that follows from it.
- State the time point: Chapter 1 birth-period, Chapter 3 awakening-period, Chapter 6 current state, or future.
- If the value changes over six years, show the progression instead of freezing the adult.

## 5. Audit rule for future work

Before writing new prose or status answers, scan for vague current-state words:

- vague age-boundary label
- exact rank open
- unresolved exact parent soul-power number
- exact parent rank/title left open after the family affects mechanics
- solid mid-rank with no level
- low-rank utility with no level
- around / roughly / likely where a mechanical number is required

If the value affects a live mechanical consequence, replace it with an exact locked value or explicitly mark it as future-only and non-mechanical.
