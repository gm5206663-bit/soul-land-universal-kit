# 08 — CONTINUITY LAW [REBUILT from kit references — originals not in this upload]

The law that produced the phrase "seventeen arithmetic errors and one hard canon
violation in a single serial." Continuity is not a habit; it is a table you check
before you write, not after.

---

## 1. THE ANCHOR TABLE

Every dated event gets one row, written into `CONTINUITY.md` the chapter it happens:

```
| Chapter | In-world date/age | Event | What it constrains |
```

**Before writing any date, age, or "time later" claim in a new chapter, check the
table first.** Dates are derived from anchors, never invented in the moment. The
moment-invention of dates is the failure this law exists to stop.

## 2. PANEL ENDPOINTS FIRST

Set the panel endpoints for a chapter BEFORE drafting it:

```
START: <age/rank/position/known-by at chapter open>
END:   <age/rank/position/known-by at chapter close>
```

Write the chapter between the endpoints. If the draft drifts past an endpoint, the
endpoint moves ONLY by deliberate decision, and the panel, the ledger, and the
anchor table all move together in the same turn (two-copies law).

## 3. FORWARD REFERENCES

Every "X years later", "she would not learn until", "reserved for" claim is a debt.
It gets a row:

```
| Claim | Made in chapter | Pays off in | Status |
```

Unpaid forward references are the silent source of retroactive errors. An honest
"parked — deliberate" beats an accidental forgetting (living-world law, 03 §5).

## 4. THE CHARACTER REGISTER

Everyone named, first and last appearance. A character who vanishes for forty
chapters without a reason has been dropped by accident; the register makes the
accident visible.

## 5. ONE BIRTH YEAR

Pick one anchor year for the protagonist. Every file derives from it. Two files
carrying two birth years is not a drift — it is two protagonists. (This single
error caused the hard canon violation the kit remembers.)

## 6. THE CHECK

Before a chapter ships:

```
- Every date/age in it traces to an anchor-table row
- Panel endpoints set before drafting, matched after
- Forward references table updated
- Character register updated
- Public vs private values both recorded where they differ
```
