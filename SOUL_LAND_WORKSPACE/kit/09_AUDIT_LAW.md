# 09 — AUDIT LAW [REBUILT from kit references — originals not in this upload]

A chapter is not done when it reads well. It is done when the audit loop has run
and passed. The loop from 00: **canon, continuity, character, power, tension.**

---

## THE FIVE AUDITS (run in order, every chapter)

### 1. CANON AUDIT
- Every canon beat touched stays true to its source (04 §2's eight questions).
- No [fan] or [design] claim asserted as [canon] in prose or panels.
- The CANON_LEDGER row for the beat has a non-empty "effect on page" column —
  an empty column means the serial is set NEXT TO Soul Land (failure 1).

### 2. CONTINUITY AUDIT
- Every date/age traces to the anchor table (08).
- Panel endpoints matched; no reserved power granted early (FORBIDDEN NOW).
- Forward references updated; character register updated.

### 3. CHARACTER AUDIT (knowledge firewalls, 06)
- Does any character act on information they have no route to?
- Does any character fail to react to something they definitely know?
- Did a public event fail to produce a public consequence?
- Did a private fact leak without an earned route?
- Firewall file updated?

### 4. POWER AUDIT (05 §6)
- Did strength come from an established cause?
- What counters remain? (Nothing is absolute.)
- Does the world react to what just became public?
- Is any number in prose inconsistent with the panel?
- Has a reserved-for-later power been granted early?

### 5. TENSION AUDIT (03 §3 + 05 §5)
- What could be lost? Who could fail? Why isn't this easy? What did it cost?
- Is there a threat that can hurt someone, and a face that wants something?
- Is there a turn: something true at the end that was not true at the start?
- A chapter of only interior meditation fails and does not ship.

## THE VERDICT RULE

Findings are not suggestions. Every audit finding is either FIXED this turn or
recorded as a parked decision with a reason. "Mostly passing" is not a verdict;
zero failures is the only verdict.

## THE REBUILD THRESHOLD (03 §7)

When a reader says "nonsense", walk the five failures in order. If more than two
are true, you are not editing — you are rebuilding. Say so plainly and do it.
