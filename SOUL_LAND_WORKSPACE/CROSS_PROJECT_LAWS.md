9. Style bar met (full scenes; no kit-recap, no sticker skill names, no lecturing, no defensive narration, no parroting).
10. Project-specific never-list re-checked (see profile §III).

## C. After ANY chapter (ritual)
1. Validate against gate B again on the written text.
2. Update in the SAME turn: status panel (core rows refreshed, not appended-over), serial log, butterfly/relationship/canon ledgers, coverage doc, open-questions list.
3. Write dated audit/validation receipt.
4. Present the chapter. One position line. No recap.

## D. Corrections protocol
Name the mistake → find first point of divergence → smallest repair that preserves established truth → downstream sweep of siblings → dated receipt → user lock recorded. Never re-litigate a lock. Never weaken a checker to pass it; red-test structural checker edits.
