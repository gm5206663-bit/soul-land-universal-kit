## 1. What this audit does and does not claim

This is an item-by-item provenance audit, not a title-based reconciliation. Every material scene, factual assertion, power claim, source-event allocation, and characterization assertion in C48–C60 is assigned one of the statuses below. A fact may be compatible with canon without being **canon-proven**.

### Status key

| Code | Meaning |
|---|---|
| **N-direct** | Directly supported by the reviewed novel text at the stated chapter. The accessible text is a third-party English proxy; it is sufficient for a traceable event comparison, not a claim about official wording or comic panels. |
| **N-relocated** | A source fact is used, but the draft moves its speaker, timing, framing, or immediate context. It must not be described as the novel’s exact scene/dialogue. |
| **N-compatible** | A restrained connective description that is compatible with a direct source event but is not itself stated there. |
| **PF** | Prior Fire Phoenix continuity: established in project prose published before this rebuild. It is not original-novel canon. |
| **AU-authorized** | An intentional alternate-causality choice covered by a cited author-direction/addendum. It is not a canon outcome. |
| **Original** | New, source-neutral interpolation or original scene logic. It receives no canon credit. |
| **Unverified** | No source/design basis was found for the exact assertion. Do not promote it into fact. |
| **Conflict / correction flag** | It differs from the reviewed source. If an author addendum covers it, it remains an intentional AU divergence; otherwise it is a correction candidate. |

### Source-location abbreviations

- **NV###** = the directly read *Soul Land IV: Ultimate Fighting* English-text proxy chapter at NovelFull. Relevant directly read sequence: NV167–200. Exact URLs follow the chapter-number pattern and are listed in §2.
- **PF C##:line** = prior public Fire Phoenix project prose under `sources/storyos_current_public_layer/published-site/soul_land_4/chapters/`.
- **AUTH C##** = author authorization/addendum in `semantic_audit/`; it proves scope approval, never novel canon.
- **Draft C##:line** = the replacement-draft body line(s) being evaluated.
