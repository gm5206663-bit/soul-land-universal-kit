# canon_coverage — coverage before prose (always)

Pattern learned from `soul_land_4_fire_phoenix` → `canon_coverage/`
(useful part, adapted).

**Rule:** before any chapter's prose exists, its coverage file is written
here first: which canon source chunks that chapter consumes, fetched and
read completely, cited by chapter title/number.

```
canon_coverage/Canon_Coverage_Chapter_01.md   ← written BEFORE Chapter_01.md
```

- Never use canon material "early" (a later source in an earlier chapter).
- Never present inferred canon as verified — fetch it, cite it.
- Canon spine = SL1 novel (R1); the source numbering map grows here as
  receipts accumulate.

**State: Stage 0 — no chapters, so no coverage files yet.** This directory
exists so the protocol is already home before the first chapter is even
thinkable.
