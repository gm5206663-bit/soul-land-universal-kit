# canon_ledger.md — Template

Copy to `foundation/CANON_LEDGER.md`. This is the highest-authority file in the project.
Every row needs a source. A row without a source is a guess wearing a citation's clothes.

---

## How to use

One row per fact. Never a paragraph. If you cannot state it in one line, it is two facts.

**Confidence tags:**
- `[canon]` — stated in the source novel, donghua, or an official release.
- `[fan]` — from a wiki, secondary recap, or community consensus. Not source text.
- `[disputed]` — sources disagree. Record the disagreement; do not resolve it silently.
- `[design]` — your invention, permitted by canon but not stated in it.
- `[user ruling]` — the user decided this. It outranks every other tag.
