# timeline.md — Template

Copy to `codex/TIMELINE.md`.

Set the endpoints **before** writing. Most timeline contradictions come from choosing a
duration in prose and discovering later that it does not fit the panel.

---

## Rule 1 — One anchor, everything derived

Pick one absolute date. Every other number in the project is that anchor plus an offset.
Never state two independent absolute dates; the second one is a bug waiting to happen.

**Anchor:** year 0 = ______ (absolute: ______)

**Conversion:** absolute = anchor + age

## Rule 2 — Panels are contiguous

Each chapter's panel states a span. The next chapter starts where the last one ended. No
gaps, no overlaps. The structural gate checks this; set it up so it can.
