## 4 · How a row closes

1. The author speaks → the ruling is entered in `OPEN_RULINGS.md` verbatim or near-verbatim.
2. The default (or his flip) is propagated the same turn: the file that carried the default is edited, `SERIAL_LOG` receipted, one commit.
3. The row here is struck through with the ruling's date and pointer. **Rows are never deleted** — the question's history is part of the record.
