# CANON_LEDGER — receipts for every canon claim, every design choice, every user ruling

Rules of this ledger:
- One row per claim. Never delete a row: mark it superseded and date the supersession.
- Evidence tiers: 1 = original novel text · 2 = official donghua/manhua · 3 = official
  database · 4 = fan wiki / encyclopedia (pointer only) · 5 = secondary coverage (recaps,
  articles). Record the tier actually read, not the tier that exists.
- Status values: `[canon]` (true in source), `[design]` (this fic's invention), `[user
  ruling]` (the author decided it — overrides source status for this serial).
- When a user ruling revokes an earlier note, quote the revoked wording HERE ONLY and mark
  it revoked. Live documents never carry revoked wording.
- Absence in what we read is NOT absence in the source. A negative finding is recorded as
  "not found in {specific sources checked}", never as "canon nowhere names it".
