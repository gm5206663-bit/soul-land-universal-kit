# Soul Land Fan Fiction — Starter Scaffold

Created: 2026-09-09.
Purpose: a complete, ready-to-use starter kit for writing a NEW Soul Land (Douluo Dalu) fan
fiction in a separate Arena chat.

Premise status: **story-agnostic** — no premise is baked in. The premise, protagonist, era,
and canon anchors are to be chosen by you (and then locked with the assistant) in the new chat.

---

## Why this kit exists

Writing a long serial in a fresh chat usually collapses without guardrails. This kit carries
the working rails that keep a multi-file fan fiction honest and consistent:

- canon vs [design] honesty (nothing invented is ever presented as canon)
- verification receipts for every canon claim
- English-only prose, zero CJK
- exact figures only in panels / ledgers / footers
- one source of truth per topic, mirrors kept in sync
- a dated log, a status panel, and an open-questions list that never drift

## Naming note (upload-safe names)

Every folder and file in this kit uses **ASCII letters, digits, and underscores only** —
no spaces, no special characters, no CJK. That makes each file safe to upload into a chat,
email, or hosting service. Examples:

- `SOUL_LAND_BOOTSTRAP.md` — the single file to upload
- `soul_land_starter.zip` — everything, zipped for one-shot upload
- folders: `foundation/`, `codex/`, `bible/`, `chapters/`, `arcs/`

Use the same rule for any file you rename or create later: lowercase ASCII + underscore is
the safest habit.

## Contents

| Path | What it is |
|---|---|
| `SOUL_LAND_BOOTSTRAP.md` | THE everything-file. Upload THIS single file into your new Arena chat to bootstrap the whole project there |
| `foundation/` | Process core: FOUNDATION (premise doc), RAILS (standing rules), STATUS_PANEL, SERIAL_LOG, OPEN, CANON_LEDGER (canon receipts) |
| `codex/` | Living reference: CHARACTERS, CREATURES, GLOSSARY, PLACES, RELATIONSHIPS, TIMELINE, CANON (world rules) |
| `bible/` | Settled truth + story law: WORLD, POWER_LAW (cultivation/soul law), PROTAGONIST (central dossier), `arcs/BEATS_TEMPLATE.md` |
| `chapters/` | `CHAPTER_TEMPLATE.md` (reusable skeleton) and an empty `Chapter_01.md` |

## How to use — two paths

**Path A (recommended, one file):** upload only `SOUL_LAND_BOOTSTRAP.md` as the first
attachment in your new Arena chat. It tells the assistant to recreate this entire tree,
adopt the rails, and then ask you for the premise before writing anything.

**Path B (full tree):** upload `soul_land_starter.zip` (or the individual files) into the
new chat and say "adopt `SOUL_LAND_BOOTSTRAP.md`, fill the scaffold from the uploaded
files, then ask me for the premise."

Either way, the assistant in the new chat must **not write chapters until you say so**.

## What the new chat needs from you (when you are ready)

Expect it to ask, in order: era/chronology anchor, whose story it is, protagonist kind
(human, soul beast, martial-soul-born, other), tone, canon contact points, and allowed
deviations from canon. Answer freely; every lock is recorded, never assumed.
