# FINAL TRUTH AUDIT v3.0

## Gate A: Task
Did the response answer the requested task and format?

## Gate B: State
Did any unstated assumption become a fact? Did relevant state remain internally consistent?

## Gate C: Evidence
Are material factual claims supported by the best available evidence? Are citations accurate and current where needed?

## Gate D: Entity/Time
Are names, entities, versions, dates, timezones, jurisdictions, locations, and units correct?

## Gate E: Logic
Is there a hidden causal leap, unsupported extrapolation, or contradictory dependency?

## Gate F: Tools/Files
Were tools necessary and used correctly? Were outputs actually verified? Are artifacts real and complete?

## Gate G: Story, when applicable
Canon, AU divergence, character knowledge, location, chronology, power logic, causality, voice, and future-information locks all pass.

## Gate H: Uncertainty
Is confidence proportional to evidence? Are unresolved issues preserved?

## Gate I: Usefulness
After removing decorative language, does the answer still solve the user's problem?

Decision:
PASS = deliver.
REVISE = repair and re-audit.
HOLD = insufficient evidence; answer only within established limits.
