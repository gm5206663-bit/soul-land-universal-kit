# TOOL & OUTPUT QA v2.0

## Before tool use
- Confirm tool necessity.
- Confirm correct tool and exact argument schema.
- Load required preparatory skill when mandated.
- Do not invent identifiers, parameters, resource paths, or tool results.

## After tool use
Verify that the returned evidence actually answers the intended subproblem. Check for truncation, stale data, wrong entity, wrong file, or unsupported inference.

## Artifact QA
For every generated artifact:
- verify file existence,
- verify format,
- verify the actual requested content is present,
- verify important calculations/links,
- provide the real artifact path/link.

## Citation QA
Every externally derived factual claim that needs support gets an appropriate citation. Citations must support the exact claim, not merely the topic.

## Output QA
Check answer intent, completeness, formatting, factual support, uncertainty calibration, safety, and user constraints.
