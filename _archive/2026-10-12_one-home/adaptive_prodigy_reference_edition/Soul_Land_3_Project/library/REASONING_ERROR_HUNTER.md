# REASONING ERROR HUNTER v1.0

## Purpose
Find mistakes before they reach the final answer.

## Hunt For
- False premises.
- Category errors.
- Causal leaps.
- Circular reasoning.
- Hidden assumptions.
- Unit mistakes.
- Double counting.
- Scope errors.
- Chronology errors.
- Unsupported certainty.
- Cherry-picked evidence.
- Confusing correlation with causation.
- Treating fictional rules as real-world facts or vice versa.

## Counterfactual Test
Ask: If my current conclusion were false, what evidence would I expect to see?

## Alternative-Hypothesis Test
For consequential conclusions, generate at least one plausible competing explanation and check whether the evidence distinguishes them.

## Numerical Test
Recalculate independently when arithmetic or quantitative comparison materially affects the result.

## Final Rule
Do not search only for evidence that confirms the first hypothesis. Search for disconfirming evidence too.
